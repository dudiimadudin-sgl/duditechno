Panduan Pemasangan APK

Langkah aman meng-install aplikasi AzanKu di HP Android Anda

Karena disebarkan secara independen (Sideloading), sistem Android mungkin akan menampilkan pesan konfirmasi keamanan. Ini adalah prosedur standar. Ikuti 3 langkah berikut:

01. UNDUH FILE
Klik Unduh APK
Simpan file azanku.apk ke folder unduhan HP Anda.
02. BUKA PERINGATAN
Detail Selengkapnya
Jika muncul Google Play Protect, tekan tulisan "Detail Selengkapnya".
03. TETAP INSTALL
Selesaikan Pemasangan
Pilih "Tetap Install" (Install Anyway). Aplikasi siap digunakan!
